PRIVACY POLICYプライバシーポリシー

最終更新: 2026年9月2日

1. 本ポリシーの対象

本ポリシーは、個人が制作・運営するポッドキャスト番組「RADIOえめるーじぇ」の番組ページ、および番組の配信を自動化するために運営者が使用しているアプリケーション「RADIOえめるーじぇ」（Google OAuth クライアント）に適用されます。

本アプリケーションは運営者本人専用の自動化ツールであり、運営者以外の利用者を想定していません。運営者本人のYouTubeチャンネルへ、生成した番組音声を自動投稿する目的でのみ使用されます。

2. 収集する情報

本番組ページおよび本アプリケーションは、利用者の個人情報を収集しません。

  • 番組ページにアクセス解析ツール・広告タグ・トラッキング用スクリプトを設置していません
  • フォーム等による氏名・メールアドレス等の入力を求めることはありません
  • Cookieを利用していません

なお、番組ページはGitHub Pages上で配信されており、配信基盤であるGitHub社のサーバーによるアクセスログの取得については同社の方針に従います。運営者はこれらのログを参照できません。

3. Google APIから取得する情報とその利用

本アプリケーションは、Google APIに対して次の権限（スコープ）のみを要求します。

  • https://www.googleapis.com/auth/youtube.upload（YouTubeへの動画アップロード）

この権限は、運営者本人のYouTubeチャンネルへ番組音声をアップロードするためだけに使用します。視聴者情報・再生履歴・チャンネル分析データ・コメント等を取得することはなく、技術的にも取得できません。

本アプリケーションによるGoogleユーザーデータの取得・利用は、Google API Services User Data Policy（Limited Use 要件を含む）に準拠します。取得した情報を広告目的で利用したり、第三者へ販売・提供したりすることはありません。

4. 認証情報の管理

Google OAuthによって発行されたリフレッシュトークンは、GitHub Actions の暗号化シークレットとして保管され、番組生成の自動処理からのみ参照されます。値がログ・公開リポジトリ・配信物に出力されることはありません。

5. 第三者提供

運営者は、取得した情報を第三者へ提供・販売・共有しません。法令に基づく開示請求があった場合を除きます。

6. 本ポリシーの変更

本ポリシーの内容は予告なく変更されることがあります。変更後の内容は本ページに掲載した時点で有効となります。
