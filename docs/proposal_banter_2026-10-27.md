# オープニング掛け合いのマンネリ対策（案・第2版）

2026-10-27 作成。**まだ何も反映していません**（プロンプト・コードとも未変更）。

第2版での変更: 「一度言った好みや考え方は次も同じにする。変える時は掛け合いで説明する」というケイスケの方針を受けて、キャラ設定シートと照合の仕組みを足しました（2章・3章）。

**決定事項（2026-10-27、ケイスケ回答）**

- シートの案（好きな食べ物・朝の一杯・趣味・休みの日）はこのまま採用
- メッセージネタは (a)。何も言わずに自然に出てこなくなる
- 会話の流れで新しく出た設定は、キャラ設定シートに追加する。追加する時は、シートの設定と矛盾しないようにする
  - 実装では、放送で新しく出た設定を照合チェックが抜き出し、矛盾しないものだけを「シートの追加分」（サイトの `character_sheet_additions.json`）に自動で書き足します。台本AIと照合には、シート本体と追加分を合わせて渡します。下の3章で「設定メモ」と書いている部分は、この「シートの追加分」のことです

## 何を変えるか

- 台本プロンプトから「朝からエメがルジェにメッセージを送りまくる」例を消します。台本AIは前日の台本を知らないので、例が1つしかないと毎日それをなぞっていました。
- 雑談のお題を36種類用意して、放送日ごとに1つずつ台本AIに渡します。話を振る人もお題ごとに決めて、エメとルジェが半々で切り出します。
- **キャラ設定シート**を作って、毎回台本AIに渡します。台本ができたら、シートと照らし合わせて矛盾がないかを機械的に確かめ、矛盾があれば書き直させます。
- シートに無い設定が放送で新しく出たら**設定メモ**に自動で記録して、次回からはそれも守らせます。
- 設定を変える日は、掛け合いで「あれ？前は〇〇って言ってなかったっけ？」と説明させます。

## 3. 設定を守る仕組み

1. **シートを毎回渡す**: 台本AIへの共通の指示文（固定部）にシートを入れます。シートはめったに変わらないので、キャッシュの構造も崩れません。
2. **照合チェック**: 台本ができたら、AIにもう1回、シートと設定メモに矛盾するセリフがないかを確かめさせます。矛盾があれば、今の用語チェックと同じ流れで書き直させます。このチェックは思考ありで動かします（読み検証が思考なしで空振りしていた反省です）。
3. **設定メモ（自動記録）**: シートに無い好み・習慣・考え方が新しく出たら、照合チェックのついでに抜き出して、サイトの `character_memo.json` に記録します。次回からは台本AIに「これまでの放送で出た設定メモ」として渡し、照合の対象にもします。メモは月に1回くらい一緒に見直して、残すものはシートへ移します。
4. **設定を変える日**: シートの「変更履歴」に日付と内容を書いておきます。その日の放送にだけ「設定変更の案内」を自動で差し込み、エメかルジェが「あれ？前は〇〇って言ってなかったっけ？」と気づいて、理由を一言で説明する掛け合いを入れさせます。
5. **メッセージネタの扱い**: エメの「メッセージを送りがち」は既出の設定なので否定はしません。今後は話の主題にしないだけです。終わらせ方は2つから選べます。
   - (a) 何も言わずに、自然に出てこなくなる（おすすめ）
   - (b) 新しい仕組みの初日に1回だけ、「最近は朝のメッセージを控えてる。ルジェの睡眠を守るため」と触れて区切る
